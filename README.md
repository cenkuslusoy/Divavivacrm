# DivaViva Studio

DivaViva için mobil öncelikli ürün hazırlama ve çok kanallı satış yönetim paneli.

## V1 kapsamı
- Toplu ürün fotoğrafı yükleme
- Fotoğrafları ürün ve renk varyantları olarak gruplama
- AI destekli ürün içeriği ve SEO taslakları
- Düzenlenebilir ürün taslakları
- Web sitesi, Trendyol ve Hepsiburada için ayrı fiyatlar
- Merkezi stok yönetimi

## Geliştirme
```bash
npm install
npm run dev
```

## Durum
İlk arayüz iskeleti. Henüz AI, veritabanı veya pazaryeri entegrasyonları bağlı değil.
